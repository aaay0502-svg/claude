# 全体構成 — 妊活noteの章立て

連載（noteマガジン）として6章構成。1章＝1〜2記事を目安に、無料記事で読者を集め、要所に有料記事を配置する。

## 全体マップ

```
第1章 妊活の全体像        （無料・入口記事）
第2章 妊娠に良い栄養素      （無料＋有料）★美容との接点が最も強い章
第3章 子宮内膜を厚くする食べ物（有料向き）
第4章 子宮の温め方（温活）   （無料＋有料）
第5章 生活習慣・メンタル     （無料）
第6章 私の妊活記録         （無料・共感と導線の柱）
```

論理の流れ：**妊娠しやすい体の3条件（卵子の質・内膜の厚さ・血流とホルモン）** を第1章で提示し、第2〜4章がそれぞれの条件に対応する構成にする。読者が「なぜこの栄養/温活なのか」を迷子にならずに読める。

---

## 第1章 妊活の全体像を知る

- 妊活はいつから・何から始めるか。「30歳で始めた私」を軸に語る
- 妊娠しやすい体の3条件：①卵子の質 ②子宮内膜の厚さ ③血流・ホルモンバランス
- この記事がマガジン全体の目次を兼ねる（各章へのリンクを貼るハブ記事にする）

**記事案：** 「30歳、妊活を始めて最初に知りたかった全体像」

## 第2章 妊娠に良いとされる栄養素

機能別に整理し、各栄養素に「妊活面の働き／美容面の働き」を並記する（ここがこのnoteの独自性の核）。

| 栄養素 | 妊活面 | 美容面 |
| --- | --- | --- |
| 葉酸 | 神経管閉鎖障害リスク低減（厚労省も摂取推奨） | 細胞の生まれ変わり・血色 |
| 鉄 | 内膜形成・貧血予防 | くすみ・クマ・髪 |
| タンパク質 | ホルモン材料・内膜の材料 | 肌のハリ・髪・爪 |
| ビタミンE | 血流・抗酸化 | 乾燥・ゆらぎ肌 |
| ビタミンB群 | 代謝・ホルモン合成 | 肌荒れ・口内炎 |
| 亜鉛 | 卵子の質・ホルモン | 髪・肌のターンオーバー |

- 各栄養素に「食材例」＋「無理なく摂る工夫（コンビニ・時短）」＋「自分が意識して変わったこと」を一言添える
- 記事分割案：無料「なぜ妊活の栄養は美容の栄養と同じなのか」→ 有料「栄養素別・完全ガイド」（→ 02_有料記事設計.md）

## 第3章 子宮内膜を厚くする食べ物

- 内膜の厚さの一般的な目安（8〜12mm程度とされる、という紹介にとどめる。診断的な断定はしない）
- タンパク質・鉄・ビタミンEを中心にした内膜特化の食材リスト
- 「内膜の厚み」と「肌のハリ」を同じ血流の話としてつなぐ（美容読者への橋）
- 食事だけで完結させず、睡眠・ストレスとの関係にも触れて説得力を出す

## 第4章 子宮の温め方（温活）

- なぜ冷えが妊活に良くないとされるか：血流 → ホルモン・栄養の供給 → 内膜形成、という流れで説明
- 具体策：腹巻／靴下／足湯／入浴法／骨盤まわりのストレッチ／温める食材（生姜・根菜・スパイス）
- NG例も載せて実用性を上げる（カイロの直貼り、熱すぎる長風呂など）
- 美容側の言い換え：「冷え性改善・むくみ・巡り美容」として同じ内容が刺さる

## 第5章 生活習慣・メンタル面

- 睡眠、運動、カフェイン・アルコールとの付き合い方
- 情報の波との付き合い方（「あれもこれも」で疲れないための取捨選択 — 自分がnoteを書く動機そのもの）
- メンタルケア。ここはHISAKOさん的な「キレイゴト抜き」のトーンで、頑張りすぎない妊活を打ち出す

## 第6章 私の妊活記録（連載の背骨）

- 30歳で始めた経緯、実際に取り入れたこと、変化を感じたこと・感じなかったこと
- 「効かなかったこと」も正直に書く。それが情報記事への信頼につながり、有料記事への最大の導線になる
- 定期更新（月1など）にして、マガジンをフォローする理由をつくる
