## コンセプト（一文で）

> 妊娠しやすい体をつくる栄養と温活は、そのまま肌・髪・巡りを整える美容習慣でもある。

- 主語は「栄養素」。妊活と美容という2つの目的を、同じ栄養素の話として1本の軸で貫く。
- 情報まとめ＋自分の実体験のハイブリッド。「情報の網羅性」ではなく「実際に試した人の記録」で差別化する。
