# 執筆ガイドライン — 健康情報を扱うnoteとしての信頼性づくり

有料で健康・美容情報を売る以上、表現の正確さは記事の価値そのもの。全記事共通のルールをここにまとめる。

## 1. 表現ルール（言い切らない・盛らない）

医療・健康効果の断定は、読者への誠実さの問題であると同時に、薬機法・健康増進法の観点でもリスクがある。

**避ける表現 → 言い換え例**

| NG | OK |
| --- | --- |
| 〜を食べれば妊娠できる／不妊が治る | 〜は妊娠しやすい体づくりに役立つとされている |
| 子宮内膜が厚くなる食べ物 | 内膜の材料になる栄養を含む食べ物 |
| 冷えを取れば妊娠する | 冷え対策は血流を整える習慣として取り入れた |
| このサプリで肌荒れが治った | 私はこの栄養を意識してから肌の調子が良いと感じた |

- 実体験は「私の場合」「私は〜と感じた」と主語を自分にする。体験談は断定を避ける最も自然な形式でもある
- 特定のサプリ・商品を推す場合はPRか自腹かを明記し、効果の保証をしない

## 2. エビデンスの強さを区別して書く

情報の確度に3段階の温度差をつけ、書き分ける。

1. **公的機関が推奨しているもの**（例：妊娠を計画する女性への葉酸摂取は厚生労働省が推奨）
   → 出典を添えて自信を持って書く
2. **一般的によく言われているが、エビデンスが限定的なもの**（例：温活・「子宮を温める」系の話の多く）
   → 「〜とされている」「助産師の〇〇さんはこう勧めている」と情報源を示す形で書く。温活は「妊娠率を上げる」ではなく「冷えのつらさを和らげる・巡りを整える生活習慣」として位置づけると誠実で、美容文脈にも自然につながる
3. **自分の実感**
   → 体験として書く。効かなかったことも書く（これが最大の信頼獲得になる）

参考にした動画・書籍・公的ページは記事末に「参考」としてリンクをまとめる。

## 3. 免責事項テンプレ（有料記事の末尾に入れる）

> ※本記事は、私自身の妊活経験と、公開されている情報をもとにした体験・情報のまとめです。医学的な診断・治療に代わるものではありません。体調や治療に関する判断は、必ず医師・専門家にご相談ください。

## 4. トーンと文体

- 語り口：友人に話すようなですます調。専門用語には一言の説明を添える（例：「子宮内膜＝受精卵のベッドになる部分」）
- HISAKOさん的な「キレイゴト抜き」を意識しつつ、他人の選択（治療する/しない、頑張る/休む）を否定しない
- 数値や基準（内膜の厚さ、摂取量など）は「一般的に〜とされる」と紹介にとどめ、読者個人への当てはめは医師に委ねる
- 妊活はセンシティブな話題。「〜すべき」「〜しないと妊娠できない」という不安を煽る書き方はしない。読後感は「今日からこれだけやってみよう」と思える軽さで終える
